# Comparador de AFD

Aplicación web interactiva para la creación, simulación, minimización y comparación de **Autómatas Finitos Deterministas (AFD)**.

El proyecto permite validar autómatas, visualizar grafos en tiempo real y verificar equivalencia formal mediante algoritmos clásicos de teoría de lenguajes formales.

# Descripción del Proyecto

El sistema fue desarrollado como una herramienta didáctica para facilitar el aprendizaje y análisis de los AFD mediante simulaciones visuales y algoritmos formales.

La aplicación permite:

- Crear y editar autómatas.
- Validar estructuras de AFD.
- Simular cadenas paso a paso.
- Minimizar autómatas.
- Comparar equivalencia entre AFD.
- Visualizar grafos interactivos.

---

# Objetivos

## Objetivo General

Construir una herramienta web para trabajar con Autómatas Finitos Deterministas (AFD).

## Objetivos Específicos

- Editar y validar AFD en tiempo real.
- Simular cadenas con animaciones.
- Minimizar AFD mediante refinamiento de particiones.
- Verificar equivalencia utilizando BFS sobre el autómata producto.
- Visualizar autómatas como grafos interactivos.

# Instalación y Ejecución

## Clonar el repositorio

```bash
git clone https://github.com/jonathandq21/Comparador-AFD-AUTOMATAS
```

## Entrar al proyecto

```bash
cd Comparador-AFD-AUTOMATAS
```

## Instalar dependencias

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```
